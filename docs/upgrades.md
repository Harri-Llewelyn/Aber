# Upgrading Aber

**This page moved to [`help/site/upgrading.md`](../help/site/upgrading.md),** so the dashboard's
help panel can show it on a site with no internet. Every heading is the same there, so the anchor
of an old link to this page names a heading on that one.

Upgrading is still one `helm upgrade` of the published chart, with the same values the site
installed with. The help page gives the command, what carries on untouched, and what needs your
attention.
