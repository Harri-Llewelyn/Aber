# Documentation for contributors

This folder is for people who work on Aber's code. It holds the design documents, the API
specifications, the testing and release guides, and the security model.

To install Aber or use it, start in [`help/`](../help/README.md) instead. It holds the install
guide, the tutorial, the glossary and the dashboard's help.

The [architecture overview](architecture.md#repository-map) lists every folder in the repository
and what each covers. Each component's own README sits beside its code.
